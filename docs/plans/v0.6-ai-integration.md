## Build Steps

1. **`LLMChat` port** (`src/growth/application/ports/llm.py`):
   - `chat(system: str, user: str, *, temperature=...) -> str` (or lightweight `ChatResponse` DTO).
   - Typed failure: `LLMUnavailableError` (mirrors `EmbeddingUnavailableError` in embeddings port).
2. **`OpenAICompatibleChat`** (`src/growth/infrastructure/llm/openai_compatible.py`):
   - httpx-based `POST {base_url}/chat/completions`, non-streaming, JSON body
     `{model, messages, temperature}`; headers `Authorization: Bearer {api_key}`.
   - Timeouts, HTTP error mapping → `LLMUnavailableError`, response parsing (choices[0].message.content).
   - Zero new deps (httpx already in pyproject).
3. **Settings** (`kernel` / settings module): `GROWTH_LLM_BASE_URL`, `GROWTH_LLM_MODEL`,
   `GROWTH_LLM_API_KEY` — mirror the `GROWTH_OLLAMA_*` pattern. `.env` is gitignored.
4. **`AiInterpreter`** (application layer): free text / natural-language plan → `CanonicalPlan`.
   - Uses `LLMChat` port (advisory); on `LLMUnavailableError` falls back to `HeuristicInterpreter`
     (offline-first, queries never break).
   - Prompt versioned (`prompt_version` in `DecisionArtifact`).
5. **Wiring** (`kernel/bootstrap.py` + `container.py`): wire real `LLMChat` when
   `GROWTH_AI_ENABLED=true`; Noop otherwise. Keep import-linter contracts (3) green.
6. **CLI**: `growth plan ai-apply <text>` (or extend `plan apply`) — dry-run default, show
   `DecisionArtifact` (model, cost_estimate, reasoning) before applying.
7. **Tests** (target 100% on new files):
   - Adapter: httpx `MockTransport` — happy path, auth header, timeout, 401/429/5xx → `LLMUnavailableError`, malformed JSON.
   - AiInterpreter: golden prompts, fallback to HeuristicInterpreter on failure, artifact fields.
   - Bootstrap: enabled/disabled wiring. Settings: env overrides.
8. **CI gate**: ruff ✅, mypy strict ✅ (new files typed), import-linter ✅, pytest ✅, coverage ≥ 98%.
