# Growth OS

A personal growth operating system — planning, knowledge management, learning, review, and execution.

> **Status:** Pre-alpha bootstrap. See [ROADMAP.md](ROADMAP.md) for the implementation plan.

## Quick start

```bash
# Install dependencies
make dev

# Run
uv run growth --version
```

See [docs/runbooks/development.md](docs/runbooks/development.md) for the full development setup guide.
